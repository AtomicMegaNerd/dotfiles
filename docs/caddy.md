# Caddy

## Caddy Reverse Proxy

[Caddy](https://caddyserver.com) runs as a Podman container on blahaj and terminates TLS for internal hostnames. See [caddy.nix](../hosts/blahaj/caddy.nix).

| Hostname                 | Upstream                                                     |
| ------------------------ | ------------------------------------------------------------ |
| `pihole.megaparsec.ca`   | `[fd00::10]:80`                                              |
| `freshrss.megaparsec.ca` | `[fd00::11]:80`                                              |
| `monitor.megaparsec.ca`  | `[fd00::12]:8090` (Beszel Hub; WebSocket read timeout: 360s) |

The Caddyfile is generated by Nix. To change it, edit `caddy.nix` and run `nh os switch .`.

### Check Status

```bash
systemctl status podman-caddy
journalctl -u podman-caddy -f
```
